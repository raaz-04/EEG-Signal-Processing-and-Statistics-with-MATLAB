# 🧠 EEG Signal Processing and Statistics with MATLAB

A structured learning repository documenting my ongoing journey in **EEG signal processing, neuroscience, time-series analysis, spectral analysis, connectivity analysis, and statistics using MATLAB**.

This repository contains my notes, MATLAB implementations, exercises, problem-solving challenges, and practical work developed while progressing through the course.

## 📚 Course Overview

This course uses **brain electrical activity as a practical application for learning signal processing, data analysis, and statistics**.

The main focus is on understanding how EEG signals can be processed, visualized, analyzed, and statistically evaluated.

### Main Topics

- EEG Analysis
- Time-Series Data Analysis
- Statistics

- Spectral Analysis
